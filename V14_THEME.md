# v14 — Midnight Pearl

This pass replaces the Royal Sapphire visual system with a restrained premium dark theme.

- Carbon / graphite surfaces instead of jewel-blue gradients.
- Warm ivory typography and champagne-metal accents.
- Sage and muted rose reserved for status semantics.
- Flatter panels, finer borders, softer shadows, and lower visual noise.
- Cleaner navigation labels and calmer controls.
- Dashboard charts recolored to the same restrained palette.
- Existing v13 privacy, rewards, chore trade, family polls, bulletin, data, and rotation logic are unchanged.
