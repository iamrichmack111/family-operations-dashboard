# v15 Ultraviolet Neon

This release replaces Midnight Pearl with a controlled ultraviolet cyber theme while preserving the v14 application behavior and database.

## Palette

- Background: `#070810`
- Raised panel: `#10121D`
- Primary ultraviolet: `#8B5CFF`
- Electric cyan: `#29E7FF`
- Electric blue: `#4385FF`
- Accent pink: `#FF4FD8`
- Success: `#46F5A3`
- Warning: `#FFD166`
- Danger: `#FF5577`

## Design changes

- Near-black panels with thin ultraviolet/cyan edge lighting
- Subtle cyber grid and ambient background glow
- Glowing active navigation, buttons, focus rings, progress meters, and chart lines
- Recolored dashboard and report charts
- Restrained pink usage so the UI stays readable instead of becoming rainbow-heavy
- Matching login screen and parent/household feature surfaces
- Reduced-motion support keeps animations optional
