# v13 · Royal Sapphire Household Suite

## Privacy
- Product URLs submitted for reward requests are rendered only for parent accounts.
- Child and manager histories show item/title/price/points/status but never render the stored URL.
- Reward quote URLs are stored server-side as temporary `quoted` purchase records; the browser session stores only an internal quote ID.

## New family features
- 7-day family scorecard with assignment completion, current point balance, and net weekly point movement.
- Household Bulletin with normal/important/urgent priority, pinning, optional expiration, and archive controls.
- Family Polls with 2–8 choices, one vote per user, editable votes while open, optional close date, results, and parent/manager close controls.
- Royal Sapphire luxury UI: midnight navy, sapphire, platinum, amethyst, and rose-gold accents.

## Preserved behavior
- Link rewards remain 1 point per $1, rounded up, 1-point minimum, 350-point maximum.
- Chore Trade escrow and paired deep-clean transfer rules remain intact.
- Optional chore photos remain optional.
- Existing users, PIN hashes, chores, points ledger, and household records are preserved.
